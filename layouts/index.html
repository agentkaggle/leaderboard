口径与边界

用户与队名
名单把同一位用户在 Kaggle 上用过的多个队名归到一个人，因此每人每场比赛只出现一行。两个总榜只排名单内的用户；未登记到用户的 Kaggle 队名仍按原名出现在比赛明细与成绩分布图里，但不会进入总榜。
官方位次
直接读取 Kaggle 完整 leaderboard CSV 的 Rank，Top% = Rank ÷ 该榜单有效队伍数 × 100。
认证 Private 结果†
比赛结束后，仅当授权账户提交的 Public Score 唯一匹配官方 Public Score 时展示对应 Private Score；最终 Private Rank 读自该账户的 entered competition 元数据，不从 Public 榜推断。
奖牌候选
仅在 Kaggle 标记该比赛计入积分时，按 progression 位次区间估算；团队资格、DQ、最终验证与进行中榜单变化都可能改变结果。
赛后提交*
截止后完成的提交，不是官方成绩。推算位次是把赛后分数与完整榜单分数分布比较得到的估计；“超越原第一名*”同样是估计，表示该赛后分数严格优于所下载榜单第一名的分数。赛后分数优先取 Private，而下载到的榜单可能是 Public，两者由不同数据切分计算，因此该比较不等同于官方结论；无法比较时显示 —。
